# Педслово

Образовательный портал для юных дарований, студентов и абитуриентов, преподавателей и профессионалов, а также взрослых любителей музыки.

Проект строится полностью на Laravel 9 / PHP 8.0+ без Moodle. Тесты и интерактивные учебные модули поддерживаются через iSpring/SCORM 1.2 и SCORM 2004.

## Что уже реализовано

- древовидные разделы и специальности;
- материалы и привязка материалов к разделам;
- учебные курсы по специальностям и 1–4 курсам;
- уроки курса;
- запись пользователя на курс;
- прогресс по урокам;
- загрузка и запуск SCORM-пакетов iSpring;
- хранение SCORM-попыток и результатов;
- административные CRUD-разделы для разделов, материалов, курсов и SCORM;
- стартовое заполнение структуры Педслово через DatabaseSeeder.

## Первый запуск

```bash
composer install
cp .env.example .env
php artisan key:generate
# настроить DB_* в .env
php artisan migrate --seed
php artisan storage:link
php artisan serve
```

После `--seed` создаётся тестовый администратор:

- email: `admin@pedslovo.local`
- password: `ChangeMe123!`

Пароль необходимо сменить после первого входа.
